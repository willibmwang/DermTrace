Two different reasons a matrix is missing

The public-cohort matrices were never committed and are gitignored.

The bulk, microarray, single-cell and spheroid tables were committed until 2026‑07‑09, when commit e625f2f stopped tracking them. Those versions are preserved under data/processed/archive/2026-07-09/.

Quickstart

From clone to a loaded matrix.

Reading the data needs only pandas and pyarrow. Everything heavier — reproducing KeloidBench, rebuilding the RNA-seq pipeline — is optional and documented separately.

# 1. get the repository
git clone https://github.com/willibmwang/DermTrace.git
cd DermTrace
python3 -m pip install pandas pyarrow

# 2. load the in-house oxygen-tension dataset
python3 - <<'PY'
import pandas as pd

tsao = "data/processed/tsaolab_o2"
tpm  = pd.read_csv(f"{tsao}/tsaolab_o2_human_tpm_symbol.tsv.gz", sep="\t", index_col="gene_symbol")
meta = pd.read_csv(f"{tsao}/tsaolab_o2_human_sample_metadata.csv", index_col="sample_id")

print(tpm.shape)   # (43478, 48)
print(meta.shape)  # (48, 40)
PY

In-house dataset

Oxygen-tension RNA-seq, with its identities checked.

Sixty bulk RNA-seq samples — 48 human, 12 mouse — across two Quintara orders. Five submitted cell lines, four oxygen arms, triplicate.

Read this before interpreting anything

SNP genotyping against a 1,500-transcript mini-reference found three identities that differ from the submission forms: twelve samples submitted as NIH3T3 mouse fibroblasts are HEK293-like human cells; ten of twelve BJ samples in the 2024 order carry HEK293-like admixture; and six samples submitted as the ATCC keloid line are BJ by genotype.

In practice that means six real keloid samples, not twelve, keloid versus BJ confounded with sequencing order, and keloid samples present in only two of the four oxygen arms.

Predecessor project

KeloidBench, kept as published.

KeloidBench is the keloid-only project DermTrace grew out of: an interpretable pipeline for keloid-versus-unaffected-skin transcriptomic classification. Its site is preserved here as an archive, and its code and results live in the repository under keloidbench/.

KeloidBench: Interpretable machine learning on fibroblast program features for keloid detection.
William Wang, Joshua Tam, Hensin Tsao · NeurIPS 2026 Workshop on Generative AI for Health, Sydney.

It is a research demonstration. Its development results do not establish clinical performance, and the reported numbers carry caveats that are worth reading in full.
