# Revision figures

Generated by `python scripts/generate_revision_figures.py` from `evaluation.json`, `matched_summary.csv`, and the narrative audit runs.

- `paper_cross_study`: camera-ready Figure 2 replacement (all eight studies; matched marker/program comparison).
- `narrative_audit`: camera-ready narrative audit figure (template vs. LLM narratives; by decision).
- `all_study_loso`, `results_overview`, `matched_markers`: larger website/report versions.

All-study bars use the documented donor/sample rule. The subset is post hoc; marker comparisons use a separate matched revision-time protocol. SVG, PNG, and PDF are supplied.
