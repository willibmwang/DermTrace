## Facts to use (source: github.com/willibmwang/KeloidBench, `results/reviewer_revision/`)

Primary evaluation, historical nested LOSO ensemble, endpoint keloid vs. unaffected skin:
- All 8 eligible studies, 101 profiles, 48 donors.
- Metric: equal-study macro F1. Within each study, predictions are averaged per donor when there are multiple class-pure donors; otherwise scoring is per sample.
- Mean macro F1 0.826 (descriptive study-bootstrap 95% interval 0.631 to 0.970). The worst study is GSE173900 at 0.182. Pooled accuracy is 78.2% (79/101).
- Selective triage at confidence threshold 0.55: mean coverage 81.4%; sample-level macro F1 on retained cases 0.838.
- A seven-study subset that excludes GSE173900 gives 0.918 mean macro F1 (worst 0.762; pooled accuracy 83.7%, 77/92). This exclusion was made after observing GSE173900's outer-fold failure, so the subset is a post hoc sensitivity analysis, not the primary estimate. Do not call it "transferable", and do not claim the failure reflects the whole sequencing platform.
- The prior "~0.92 weighted F1" and "~0.84 accuracy outside LOSO" both come from this post hoc subset. The 0.84 figure is LOSO pooled accuracy, not a non-LOSO result.
- The model fails the pre-set development gates (mean 0.85, worst study 0.75).

Matched marker vs. program comparison (new; same eight studies, outer folds, weighting, train-only imputation and scaling, L2 logistic regression with C in {0.1, 1, 10}, inner-LOSO selection, Platt calibration, and thresholds for every arm):
- Single markers (mean / worst macro F1): COL1A1 0.914 / 0.444; COL3A1 0.861 / 0.182; POSTN 0.826 / 0.325; FN1 0.818 / 0.325; CTHRC1 0.809 / 0.182; ACTA2 0.356 / 0.143.
- Program views: rank programs 0.896 / 0.416; scar-discriminative 0.842 / 0.416; fused multiview 0.836 / 0.325; fibrosis 0.802 / 0.182; composition 0.750 / 0.325.
- Feature family chosen inside each outer training fold: programs 0.855 (worst 0.416) vs. markers 0.829 (worst 0.182). Paired difference +0.025, with a descriptive study-bootstrap interval of -0.108 to +0.148.
- Conclusion: programs are competitive and had a better worst-study score in this comparison, but general superiority over single markers is not supported. COL1A1 alone was the best fixed arm, and choosing it after seeing the table is descriptive only.

Narrative audit (new). Evidence packets were frozen for all 101 profiles (21 are abstentions), with 3 greedy requests per profile. Automated checks cover the exact factual opening, no added numbers, decision consistency, abstention disclosure, the QC note, a final disclaimer, contribution direction, prohibited claims (diagnosis, treatment, causation, citations), length, request redaction, packet immutability, and truncation.
- The deterministic template passes 101/101.
- v1, frozen before generation: Qwen3-1.7B writes the whole narrative and passes 0/303. Every output echoed the prompt's section labels. After the labels were stripped post hoc, 6/303 passed. Outputs restated numbers despite instructions, and 255 of 933 program-attributed numbers were input values described as contributions.
- v2, frozen and published before generation but designed after seeing v1: Qwen3-8B writes only the sentences about contribution direction. Code inserts the probability, decision, QC note, and disclaimer, so no number or class label is model-generated. A stricter clause-level direction check was added. Result: 290/303 passed all checks (95.7%; profile-cluster 95% interval 0.917 to 0.990), and 96/101 profiles passed on every repeat. All 13 failures assigned a program the wrong direction.
- Post hoc, 75/303 v2 outputs contained a non-English token (code-switching), so 215/303 (71.0%) were both check-passing and English-only. The demo shows generated text only if it passes every check and is English-only; otherwise it shows the labeled deterministic template.
- Limitations: v2 is development-informed on the same packets, the checks are automated screening rather than semantic proof, and independent human rating was not performed.

Other provenance:
